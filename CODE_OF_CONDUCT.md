# Code of conduct

Cadenza should be a respectful, practical place to collaborate. Treat other people with
consideration, assume good faith, and critique ideas and code without attacking the person
behind them.

Harassment, discrimination, threats, sexualized attention, doxxing, and publication of
another person's private data are not acceptable. Meeting recordings, transcripts,
credentials, and security reports must never be posted to demonstrate a bug; use synthetic
data and the private process in [SECURITY.md](SECURITY.md).

Maintainers may edit or remove content, close participation, or restrict access when
behavior puts people or their data at risk. If you need to report conduct privately, ask
the repository owner through their GitHub profile for a private contact channel. Reports
will be reviewed as promptly and confidentially as practical.

By participating in this project, you agree to follow these expectations in repository
issues, pull requests, discussions, and project-related communication.

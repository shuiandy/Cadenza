# Security Policy

## Supported versions

Security fixes are made on the latest released version and the current default branch.
Older builds may be asked to update before a fix is provided.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository (the
**Security** tab, then **Report a vulnerability**). Do not include secrets, recordings,
transcripts, access tokens, or personal meeting data in a public issue.

Include the affected version or commit, the security boundary that fails, reproduction
steps, impact, and any suggested mitigation. Use synthetic data wherever possible.

If private vulnerability reporting is unavailable, contact the maintainer through the
GitHub account that owns this repository and ask for a private reporting channel before
sharing details.

## Scope

Useful reports include unauthorized access to local recordings or credentials, unsafe
OAuth or MCP behavior, unintended cloud uploads, permission prompts from background paths,
archive integrity failures, and paths that escape a user-selected storage root.

Please do not test against other people's accounts or data, disrupt third-party services,
or publish a working exploit before a coordinated fix is available.
